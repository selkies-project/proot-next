# proot-next 0.3.1

## Fixes

- A file or directory bound to a guest path that does not exist now shows
  in its directory's listing, not only when looked up by name. Loaders that
  find drivers by listing a directory missed vendor files bound in one by
  one: under proot-apps with an NVIDIA GPU, libglvnd and the Vulkan loader
  only saw Mesa, so Chrome rendered without the GPU. As in PRoot, the
  missing mount point is created in the rootfs for the run and removed on
  exit; one left by a supervisor that was killed is removed by the next
  launch. `PROOT_DONT_POLLUTE_ROOTFS` turns this off. The same applies to a
  bwrap bind inside another bind.
