# proot-next 0.3.7

## Fixes

- `linkat` with `AT_SYMLINK_FOLLOW` on a `/proc/self/fd` link links the file
  the link names, which is how an `O_TMPFILE` is published (Qt's
  `QTemporaryFile` and `QSaveFile` do so). The flag was dropped for such a
  link, so the kernel was asked to link the procfs link itself and refused
  with `EXDEV`, or `ENOENT` on another kernel: Telegram Desktop could not
  extract its fonts. Without the flag the link is refused as it is natively.
